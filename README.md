# Sponsor Ticker v5 — непрерывная бегущая строка

## Что исправлено
- Логотипы позиционируются индивидуально; нет перезапуска или удаления целой группы.
- Логотипы движутся справа налево с постоянным шагом 18 px.
- Достаточное число повторов покрывает всю ширину окна при любом положении анимации.
- Настройки берутся из существующего `overlay-sponsors.json`.
- `?enabled=off` полностью скрывает рекламную строку.

## Установка
1. В репозитории `norcis2/Tablet-Scoreboard` замените **только** корневой `sponsor-ticker.html` одноимённым файлом из архива.
2. Нажмите **Commit changes** и дождитесь публикации GitHub Pages.
3. Откройте `https://norcis2.github.io/Tablet-Scoreboard/sponsor-ticker.html?v=5`.
4. В OBS/Streamlabs обновите Browser Source (Refresh cache of current page) или добавьте `?v=5` к URL.

Остальные файлы менять не требуется. Параметры скорости, высоты и прозрачности остаются в `overlay-sponsors.json`.

## Проверка
Наблюдайте 2–3 минуты, чтобы убедиться в отсутствии пустых областей и скачков.

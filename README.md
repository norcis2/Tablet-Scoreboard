# Tablet Scoreboard — YouTube / OBS Overlay

Репозиторий: https://github.com/norcis2/Tablet-Scoreboard

## Установка без изменения планшетной версии v15

Добавьте в **корень существующего репозитория** только два новых файла:

- `overlay.html` — полупрозрачное табло для трансляций;
- `overlay-sponsors.json` — **отдельный список спонсоров трансляции**.

Существующие `index.html`, `tablet.html`, `api-config.json`, `tournament.json`, `sponsors.json` и папки с изображениями **не заменяйте**. Новая версия использует их для Rankedin и названия турнира, но читает **только** `overlay-sponsors.json` для рекламного блока.

## Адреса

- Court 1: `https://norcis2.github.io/Tablet-Scoreboard/overlay.html?court=1`
- Court 2: `https://norcis2.github.io/Tablet-Scoreboard/overlay.html?court=2`
- Аналогично Court 3–7 после заполнения ID в `api-config.json`.
- Тест: `https://norcis2.github.io/Tablet-Scoreboard/overlay.html?court=1&demo=live`
- **Без рекламы**: `https://norcis2.github.io/Tablet-Scoreboard/overlay.html?court=1&sponsors=off`
- Тест без рекламы: `https://norcis2.github.io/Tablet-Scoreboard/overlay.html?court=1&demo=live&sponsors=off`

## Независимые спонсоры

`overlay-sponsors.json`:

```json
{
  "generalSponsor": "sponsors/Squashop.jpeg",
  "partners": ["sponsors/Maxima.png"],
  "generalSeconds": 10,
  "rotationSeconds": 10
}
```

Здесь в YouTube показываются **только Squashop и Maxima**. Pepsi centrs и Meste продолжают показываться на планшете, если они прописаны в `sponsors.json`.

Поведение: при наличии генерального спонсора и партнёров сначала 10 секунд показывается генеральный спонсор отдельно, затем 10 секунд — генеральный вместе с партнёрами. При большем числе партнёров они чередуются группами по три. Без генерального спонсора партнёры показываются группами до четырёх. Если партнёров нет, но есть генеральный, он показывается постоянно.

**Полностью скрыть рекламу настройками**:

```json
{
  "generalSponsor": null,
  "partners": [],
  "generalSeconds": 10,
  "rotationSeconds": 10
}
```

Или добавить `&sponsors=off` к адресу в OBS — это временно скрывает весь блок (фон, рамку, отступы), **не изменяя JSON**. Параметр `sponsors=off` относится только к `overlay.html` и не влияет на планшеты.

Файлы изображений должны находиться в папке `sponsors/`. Имена с пробелами и расширения `.png`, `.jpg`, `.jpeg` поддерживаются. Если загружаете новый логотип, добавьте файл в папку и укажите его путь в JSON.

## Подключение к OBS Studio / Streamlabs Desktop

1. Создайте источник **Browser / Browser Source**.
2. Вставьте ссылку `overlay.html?court=1`.
3. Укажите **Width: 1920**, **Height: 1080**.
4. Разместите источник **выше** видеозахвата корта в списке источников.
5. Не включайте собственную непрозрачную заливку фона браузерного источника. У страницы фон прозрачный.
6. Проверьте сначала `&demo=live`, затем удалите `demo=live` для реальных данных.
7. Для другого корта поменяйте `court=1` на `court=2` и т. д.

Табло расположено компактно вверху по центру; блок спонсоров непосредственно под счётом. Основное видео остаётся видимым через прозрачный фон страницы. Сами панели табло полупрозрачны.

## Rankedin

Источник данных берётся из `api-config.json` (общий для планшетов и трансляций). По умолчанию Court 1 = Rankedin ID `192806`, обновление каждые 5 секунд. При активном матче показываются очки, геймы и подача; при отсутствии активного — следующий матч либо COURT AVAILABLE. После завершения наблюдаемого прямого матча результат удерживается примерно 60 секунд. При первом открытии после уже завершившегося матча он не показывается автоматически.

Если Rankedin меняет структуру API, потребуется обновление JavaScript. Доступность JSON напрямую не гарантирует, что запрос из GitHub Pages разрешён браузером (CORS).

## Обновление настроек и проверка

После изменения `overlay-sponsors.json` сделайте **Commit changes** и обновите Browser Source в OBS. Файл конфигурации перечитывается примерно раз в 60 секунд. Проверьте, что изменения опубликованы GitHub Pages. Если OBS показывает старую версию, обновите кеш Browser Source или добавьте временный параметр `&v=2` к ссылке.

## Примечания

- Пакет добавляет оверлей и **не изменяет работающий планшетный v15**.
- Дизайн адаптирован под трансляцию 1920×1080; перед эфиром проверьте размеры на реальном видеопотоке.
- Встроен демонстрационный режим `demo=live` и `demo=next`.
- Реальный эфир с Rankedin и OBS требует проверки пользователем после публикации.
